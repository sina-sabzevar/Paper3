# کوئری‌های ساخت لیبل

| فایل | کار |
|---|---|
| `01_build_label.sql` | جدول لیبل را می‌سازد؛ یک سطر به ازای (مشترک، کوهورت)، با ۴ نسخهٔ لیبل |
| `02_label_report.sql` | ۶ کوئری گزارش که تصمیم آستانه را می‌گیرند |

## ترتیب کار

۱. در `01` همهٔ `[RENAME]`ها را با نام جدول‌ها و ستون‌های واقعی عوض کن
۲. لیست `cohorts` را با تاریخ‌های واقعی خودت پر کن (هر کوهورت ۱۵ ماه داده می‌خواهد)
۳. روی نمونهٔ **۱۰۰ تا ۵۰۰ هزار** مشترک اجرا کن — نه روی کل ۱۰ میلیون
۴. `02` را اجرا کن و خروجی **Q1، Q3، Q4، Q5** را نگه دار

## خروجی که تصمیم می‌گیرد

- **Q1** → کدام نسخهٔ لیبل در بازهٔ ۵ تا ۱۵ درصد می‌افتد
- **Q3** → اگر `rule2` خیلی بیشتر از بقیه شلیک می‌کند، `LATE_DAYS` شل است
- **Q4** → توزیع واقعی DPD؛ `LATE_DAYS` باید بالای تودهٔ اصلی باشد
- **Q5** → منحنی بازگشت؛ `BAD_DPD` را از زانوی این منحنی بردار، نه از حدس

مشخصات کامل در `../label_spec.md`.
